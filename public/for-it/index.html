For IT staff and implementers

One server runs everything. The installer takes about 30 minutes and asks six questions; countyctl handles the rest. This page is the short version of the administrator guide.

Server size

MinimumRecommended
Operating systemUbuntu 22.04 LTS or Debian 12Ubuntu 24.04 LTS
Processors24
Memory4 GB8 GB (16 GB above about 5 million record pages)
Disk for the system20 GB40 GB
Disk for dataDepends on record images; the sizing guide shows how to estimate from a sample of your own scans

A virtual machine is fine, on your own hardware or in a cloud. The portal needs ports 80 and 443 to itself.

Install

On a fresh Ubuntu 24.04 server you can SSH to with sudo, the install guide walks through: update the OS, install git, clone the repository, run deploy/install.sh. It asks six questions (the government's name and type, the state, the web address, the certificate type, and the first administrator), installs Docker, builds and starts the portal, takes the first backup and prints the administrator's sign-in. Running it again is safe. A free automatic HTTPS certificate is issued when the address points at the server and ports 80 and 443 are open.

Want to see it first? Run a local copy in three commands with Docker, or use the hosted demo county.

Operate

  • Backups. Every night the server copies the database, snapshots images and uploads, and copies the backup off the server if you've set that up. The last 14 nightly backups are kept; labeled backups (before an update, a restore, or by hand) for 60 days.
  • Updates. A backup is taken first, and if the new version doesn't start properly, the old one comes back on its own with your data as it was. Versions follow semantic versioning; 1.x updates never require manual steps.
  • Migration. A toolkit for records, bills and the old website, with dry runs, verification, sign-off and undo for every import.
  • Payments. Processor adapters (Stripe Checkout, pay-at-office, and a test processor for training); new adapters are contributed back to the project.
  • Conformance. Run the same suite the project runs on every pull request against your own installation: axe-core WCAG 2.1 A/AA checks on every public page at desktop and 320-pixel phone widths, the API contract, and the data catalog.

Implementers

Most of the more than 3,000 counties and about 40,000 special districts in the United States can't spare a developer. Independent IT consultants, small firms, regional councils of government and state associations install and look after the portal for them, and may charge for it. The implementer guide sets the ground rules: the county owns everything, fixes are contributed back, no lock-in by any means, and nothing is handed over that fails the conformance suite.
