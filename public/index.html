A free, open-source website for counties, cities and special districts

Open County Portal gives a local government a complete public website: services and offices, meetings and notices, property records search with free copies, online payments, a counter point of sale for cashiers, online forms, public information requests, and a free open API for all public data. No license fee, ever. Yours to run.

What it does

For residents

  • Services, offices, hours and contacts, in plain language
  • Meetings, agendas and minutes; public notices
  • Property records search, page images, free uncertified copies, and certified copies with an online verification code
  • Pay property tax, court costs, utility bills and fees, in full or in part
  • Online forms and public information requests

For staff

  • A staff console with two-step sign-in and roles
  • Counter point of sale: drawers, cash, check, card, escrow, close-out, supervisor voids
  • Finance reports and exports for the general ledger
  • Records administration: index corrections, restriction, redaction drawn on the page, a Social Security number scan
  • Content editing, required-postings tracking, a go-live checklist, an audit log

For administrators

  • A one-command installer and a countyctl command for status, backups, restore and updates that undo themselves if anything fails
  • A migration toolkit for records, bills and the old website, with dry runs and undo
  • State packs that set up a state's offices, fees, required postings and records rules (Texas included)
  • A theme editor that won't publish colors that fail contrast

For everyone

  • Open API at /api/v1, daily bulk files, a change feed, and DCAT-US catalogs that Data.gov harvests
  • Every page built to meet WCAG 2.1 AA, working on any phone, with or without JavaScript
  • A conformance suite that checks any running portal for accessibility, API and catalog problems

Run it locally in three commands

You need Docker. The first run builds the portal (5 to 10 minutes) and generates a fictional county to explore.

git clone https://github.com/OSGovt/open-county-portal.git
cd open-county-portal
./deploy/local/start.sh

Then open http://localhost:8080. The README has the Windows steps and how to erase it.
