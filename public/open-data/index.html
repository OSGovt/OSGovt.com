Open data and API

Every government running Open County Portal publishes the same free API, the same daily bulk files and the same catalog format. Code you write for one county works for all of them. No account, key, fee or contract is required.

Where to start

Replace portal.example-county.gov with the county's portal address. The demo county answers at utopia.osgovt.com/data.

What's in it

  • Recorded documents (deeds, liens, plats) with page images, image checksums and machine-read text
  • Meetings with agendas and minutes; public notices
  • Current and scheduled fees with their legal authority
  • Services, offices with hours and contacts, published information pages
  • Released public information responses
  • Everything created, changed or removed since a time, for anyone keeping a copy

All endpoints are GET, return JSON, and allow cross-origin requests from any website. The OpenAPI document is generated from the running code, so it's always exact for that portal's version.

Data.gov

The DCAT-US catalog is what Data.gov harvests, so a county's open data is listed nationally without extra work. The administrator guide covers submitting the catalog.
