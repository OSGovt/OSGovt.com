# Support

**A problem with these pages** (wrong, broken, hard to use): open an issue
with the "Problem with OSGovt.com" template, or email hello@osgovt.com.

**A problem with the software** (Open County Portal itself, the demo, the
installer, the docs): that belongs in
[OSGovt/open-county-portal](https://github.com/OSGovt/open-county-portal/issues/new/choose).

**Security:** report privately through GitHub's "Report a vulnerability" on
this repository or to security@osgovt.com. Never in a public issue.

Please don't post passwords or residents' personal information anywhere.
