# Security

Report security problems privately to **security@osgovt.com**, or with
GitHub's "Report a vulnerability" on this repository. Please don't open a
public issue. We'll acknowledge within 3 business days.

For a problem in OSGovt (Open County Portal), see that project's
[security policy](https://github.com/OSGovt/open-county-portal/blob/main/SECURITY.md).
